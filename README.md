# Math for Data Science

Interactive teaching material by Dr. Milan Joshi.

## Graphs and Trees

An interactive deck of 71 slides: graph basics, planar graphs and Euler's formula, graph colouring and the four colour theorem, dual graphs, trees and binary search trees, game trees and minimax, tree traversals, depth-first and breadth-first search, spanning trees, and Kruskal's and Prim's algorithms.

It includes six narrated video lessons with chapters and live captions:

| Slide | Video lesson |
|---|---|
| 19 | Graph colouring and the four colour theorem |
| 42 | Nim: the game tree and minimax |
| 45 | Tree traversals: preorder, inorder, postorder |
| 56 | Depth-first and breadth-first search |
| 62 | Kruskal's algorithm |
| 66 | Prim's algorithm |

### How to open it

- Online: open the GitHub Pages link of this repository.
- On your own computer: download the repository and open `index.html` in Chrome or Edge. Keep the `videos` folder next to `index.html`.

Use the arrow keys or the on-screen buttons to move through the slides and steps.
